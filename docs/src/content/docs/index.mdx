## The comparison

Three paradigms for driving GIS work with an LLM, run against production CLI agents
used as black boxes, on GeoAnalystBench tasks stratified by difficulty:

<ConditionGrid />

Two independent questions fall out of that design: **does tool-calling structure beat
free-form code** (MCP versus CodeGen), and **does adding tools help or hurt** (MCP-5
versus MCP-15). The second is the interesting one — the literature predicts an
inverted-U between tool count and performance, and no prior work has tested it in a
GIS setting.
