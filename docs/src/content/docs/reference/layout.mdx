## Where a rationale lives

| Question | Answer lives in |
| --- | --- |
| Why two environments? Why is Python caching off? | `AGENTS.md` |
| What must pass before a commit lands? | `pixi.toml`, task `gates` |
| Why is this package.json shaped like that? | a `//`-prefixed key in the file itself |
| What is the experiment measuring? | `.knowledge/`, and this site's *Experiment* section |
| What is still to do? | `backlog/tasks/`, via `pixi run backlog -- …` |

JSON files cannot carry comments and both `turbo.json` and `biome.json` reject
unknown top-level keys, so `//` keys are not an option there — that reasoning is in
`AGENTS.md` instead. `package.json` is the exception: Bun parses it as strict JSON,
and `//`-prefixed *keys* are valid JSON, which is why the manifests in this
repository carry long ones.
