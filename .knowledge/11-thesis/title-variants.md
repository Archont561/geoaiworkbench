# Thesis Title Variants

## Recommended Titles

### Polish (Thesis) ⭐
**"Ocena protokołu MCP jako metody integracji agentów LLM z narzędziami GIS w porównaniu z generowaniem kodu"**

### English (Journal) ⭐
**"To Call or To Code? Comparing MCP-Based Tool Use and Code Generation in CLI Agents for Geospatial Analysis"**

### Polish (Journal)
**"Analiza porównawcza użycia narzędzi opartego na protokole MCP oraz generowania kodu w agentowych systemach GIS — ewaluacja na zadaniach geoprzestrzennych o zróżnicowanej złożoności w środowisku QGIS"**

## Supervisor's Proposed Title

**"Analiza metod integracji agentów LLM ze środowiskiem QGIS z użyciem protokołu MCP"**

**Issue:** Sounds like a literature review. Does not expose:
- Comparative nature (vs CodeGen)
- Task difficulty dimension
- Tool count experiment
- Security evaluation

**Recommendation:** Diplomatically suggest variant #1 or #2. See [KB-11-supervisor-email](supervisor-email.md).
