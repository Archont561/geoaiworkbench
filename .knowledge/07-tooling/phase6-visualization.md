# Phase: Visualization & Presentation

## Tools

TikZ 3.1, draw.io 24.x, Excalidraw, Beamer 3.71, GIMP, Inkscape

## Details

TikZ for thesis-quality vector diagrams (architecture, flowcharts); draw.io for quick sketches before TikZ; Excalidraw for defense slides; Beamer for LaTeX presentations; GIMP/Inkscape for screenshot annotation

## Key Commands

```bash
Compile TikZ: pdflatex figures/architecture.tex
```
